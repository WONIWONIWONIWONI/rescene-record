# PULSE FIT

리센느 PULSE의 구매성향 설문, 예산 내 조합 추천, 봉입 포카 수집 계산기입니다. 빌드 없이 동작하는 정적 사이트이며 `dist/`를 정적 호스팅 루트로 사용합니다.

## 사용

`dist/index.html`과 `styles.css`, `engine.js`, `app.js`를 같은 디렉터리에 배치합니다. 설문 답변과 사용자 입력 가격은 브라우저 localStorage에만 저장합니다. 별도 수집 서버, 광고·제휴 링크, 자동 구매 기능은 없습니다.

## 추천 모형

예산에서 배송·교환 예약액을 먼저 빼고, 최대 보관 수량 1~100개 안의 정수 조합을 전수 비교합니다. CD 필수 조건은 실행 가능한 경우 반드시 지키고, 구매 불가능하면 구매 보류를 표시합니다. 포토북 최우선의 경우 구매 가능한 포토북을 최소 1개 포함합니다. 초동 최우선이면 집계 가능 수량을 먼저 최대화합니다. 수집 목표가 없으면 동일 구성 반복의 효용을 억제하고, 동점에서는 더 싼 조합을 선택합니다.

성향별 기본 첫 구매 가중치 (Standard / Limited / QR / Wappen): 균형 75/58/42/32, 포토북 100/85/15/10, 포카 32/24/80/15, 실물 소장 65/90/22/65. 수집 대상에는 풀별 수집 효용 240을 추가합니다. 교환 조건은 이론상 카드 장수 충족률, 직접 개봉 조건은 풀별 기대 도안 충족률을 사용합니다. 점수는 경험적 취향 가이드이며 금전 수익률이나 절대적 만족도를 뜻하지 않습니다.

QR 수량은 세트와 단품의 최소 비용 조합으로 변환하되, QR 전종 수집에서는 패키지가 확정되는 세트를 선택합니다. QR 5종 세트는 5개의 실물과 5개의 집계 가능 앨범으로 계산합니다. Wappen은 CD·QR 음원 미안내 및 상품별 반영 미확인으로 집계 가능 수량에서 제외합니다. 실제 초동 반영은 판매처·출고·집계 시점에 달려 있습니다.

## 포카 수집 모형

한 팩에서 전체 N종 중 서로 다른 k종을 균등하게 추출하고 팩 간 독립이라고 가정합니다. 기대 도안 수는 `N * (1 - (1 - k/N)^packs)`입니다. 완성 확률은 이미 모은 도안 개수를 상태로 갖는 동적 확률 계산이며 독립적인 포함배제 계산으로 검증했습니다.

교환 전제 최소: Standard 5개 (개인 10종 및 유닛 5종), Limited 5개 (10종), QR 5종 세트 2세트 (공통 셀피 15종 및 패키지별 4종), Wappen 5개 (5종). 모든 버전은 총 25개 실물, 상품 합계 378,500원, 랜덤 봉입 포카 80장입니다. 각 풀 내부에서 1:1 교환이 가능하다는 가정이며 실제 교환이나 완성을 보장하지 않습니다.

직접 개봉의 90% 기준은 각 풀의 기준입니다. 전체 풀을 동시에 완성할 확률은 제공하지 않으며, 풀 간 독립성을 임의로 가정하지 않습니다. QR 버전별 기대 도안·완성 확률에는 실제 세트로 확정한 패키지만 반영하고 랜덤 단품은 제외합니다. 이미 보유한 도안, 필름 포토·메시지 카드·이미지 카드·ID 포토의 완성은 이 모형의 범위 밖입니다. 판매처 특전은 아래 별도 구매 조건으로 다루며 봉입 포카의 랜덤 완성 확률과 합산하지 않습니다.

## 검증

`node test-engine.cjs`는 확률, 수집 최소 수량, 세트 단위, 예산·수량 제한, CD 조건, 수정 가격, 배송비, 초동 최적 수량을 확인합니다. `node --check dist/app.js`와 `node --check dist/engine.js`로 구문을 확인합니다. 실행 환경에 지원되는 브라우저 제어 도구가 없어 실제 브라우저 화면 QA는 수행하지 않았습니다.

홈의 버전별 이미지와 보고서 이미지는 개념 그림이며 실제 제품 사진으로 표시하지 않습니다.

설문은 9개 질문입니다. 특전 불필요 / 특전 필요(자동 또는 특정 상품) / 첨부 7개 특전 세트 전체를 선택할 수 있습니다. 비교 페이지와 특전 안내 페이지에 판매처별 가격·상품·구매 조건을 표시합니다.

첨부 자료의 7개 세트: 배민 Limited 5개 130,000원, CU QR 5종 44,500원, CU Wappen 2개 22,200원, 메이크스타 털실냥이 Standard 5개 104,000원, 메이크스타 쇼케이스 한입만 Standard 5개 104,000원, 후즈팬 Wappen 5개 55,500원, 후즈팬 쇼케이스 Standard 5개 104,000원. CU 가격은 사용자가 22,200원으로 정정하여 전체 합계는 564,200원, 포함 실물은 32개입니다. 모든 특전 세트와 봉입 포카 전종(교환 전제)을 함께 목표로 하면 QR 5종 세트 1개가 추가되어 상품 합계 608,700원, 실물 37개입니다.

[메이크스타 털실냥이 공식 이벤트](https://www.makestar.com/product/21195)에서 확인한 Standard 단품 20,800원 + 랜덤 특전 1장도 자동 추천 후보입니다. 5매를 한 주문에 구입하면 중복 없는 특전 세트를 주는 조건을 대조했습니다. [메이크스타 쇼케이스](https://www.makestar.com/product/21196)는 별도 이벤트입니다. 다른 세트의 특전 설명·가격은 사용자 첨부 자료 기준이며 행사별 주문 단위·기간·품절 여부는 구매자가 확인해야 합니다. 특전 도안 수를 확인하지 못한 경우 임의로 포카 장수나 랜덤 확률에 추가하지 않습니다.

특전 추천은 요구하는 이벤트 상품을 먼저 넣고, 그 안의 앨범 수량을 봉입 포카 목표에 합산한 뒤 일반 앨범 추가 조합을 최적화합니다. 일반 앨범 가격 설정은 특전 세트의 고정 가격을 바꾸지 않습니다. 판매처가 여러 개면 배송비·교환비를 합쳐 별도 지출 예약액에 입력해야 합니다.

예산 무제한은 boolean 상태로 저장합니다. 임의의 큰 숫자를 예산으로 대체하지 않고 금액 제한을 제거합니다. 사용자가 정한 실물 수량 상한 1~100개는 유지하며, 일반 소장 목표가 충족되면 불필요한 중복 구매를 늘리지 않습니다. 초동 최우선은 집계 가능 수량을 먼저 최대화하고, 같은 수량이면 더 싼 조합을 선택합니다.

검증: `node pulse-fit/test-engine.cjs` (18개 계산 검사), `node pulse-fit/test-ui-render.cjs` (9개 설문 및 결과 분기 템플릿 실행 검사; 실제 브라우저 레이아웃 검사가 아님). 배포 후 GitHub Actions가 비로그인 HTTP 200 및 정적 파일 내용 일치를 확인합니다.
