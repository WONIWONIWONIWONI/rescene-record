# PULSE FIT

RESCENE PULSE 구매 성향·봉입 포카·판매처 미공포·쇼케이스 응모를 함께 계산하는 정적 사이트입니다. 계정 없이 브라우저에서 작동하며 답변·수정 가격은 localStorage와 결과 공유 URL에 저장합니다. 기존 차트 사이트의 루트를 유지하고 `pulse-fit/`에 추가했습니다.

## 현재 가격 규칙

미공포 없는 앨범과 추가 봉입 수집 수량은 공구가로 예산을 계산합니다. 일반 판매가와의 최저가 경쟁은 하지 않습니다. 특전·쇼케이스 응모 상품만 해당 이벤트 가격을 유지합니다. 공구가와 미공포/응모 혜택을 같은 물량에 이중 적용하지 않습니다.

`groupbuy`는 compare/allmd/ktown입니다. 이전 none 설정과 오래된 결과 링크의 일반가 계산도 compare로 읽습니다. 선택한 공구가 마감됐어도 다른 공구가 진행 중이면 가능한 공구로 전환해 표시합니다. 모든 공구가 마감된 경우만 일반 판매가를 **참고값**으로 표시합니다. 일반 가격 편집값은 이 참고값과 일반 사양 정보용이며, 진행 중 공구의 단가를 바꾸지 않습니다.

| 구매 옵션 | ALL MD | Ktown4U |
| --- | ---: | ---: |
| Standard | 16,900원 | 17,400원 |
| Limited | 21,100원 | 21,800원 |
| QR 랜덤 단품 | 7,300원 | 8,200원 |
| QR 5종 세트 | 36,200원 | 40,700원 |
| Wappen | 9,100원 | 9,800원 |

사용자가 제공한 총공 공구 안내 기준이며 회원가입·공구 전용 링크가 필요합니다. ALL MD 마감 2026-11-09 21:00 KST, Ktown4U 마감 11-03 17:00 KST. 두 판매처 모두 11-04 이후 순차 발송 안내입니다. 안내의 일반 차트 반영 문구만으로 와펜의 상품별 반영이나 초동 기간 내 집계를 확정하지 않습니다.

공구의 앨범 봉입 사양은 일반 상품과 같으며 판매처 미공포·쇼케이스 응모는 없습니다. Ktown4U 팬버튼과 ALL MD 앨범 사은품은 포카/응모 수량에 더하지 않습니다. ALL MD 금액별 뷰티 사은품은 뷰티 상품 구매 조건이 있어 앨범 추천에서 제외합니다.

ALL MD 주문의 공구 상품값만 50,000원 이상일 때 1회 무료배송을 적용합니다. 다른 판매처의 이벤트 주문값은 합산하지 않습니다. 100,000원 이상 분리배송 신청 1회 무료는 안내만 하며 신청이나 추가 앨범 구매를 자동 수행하지 않습니다. 배송비 `groupShipping_allmd`/`groupShipping_ktown`은 정수 또는 null입니다. null은 미확인이며 무료가 아닙니다. 미확인일 때 상품가 기준 조건부 금액을 표시하고 실제 배송비 입력 후 예산에 포함해 재계산합니다. 다른 판매처 배송·교환 비용은 별도 예약액에 입력합니다.

## 앨범과 특전

공개 사양은 `engine.js` catalog의 판매처 링크로 확인할 수 있습니다. Standard 봉입 포카 3장(개인 2 + 유닛 1), Limited 2장, QR 5장(공통 셀피 3 + 해당 버전 2), Wappen 1장입니다. QR 세트는 서로 다른 패키지 5개이지 랜덤 봉입 포카의 도안 중복을 없애는 세트가 아닙니다. QR 5종 세트의 실물·차트 수량은 5개입니다. 와펜은 상품별 차트 반영 미확인으로 예상 집계 수량에서 제외합니다.

첨부 자료의 특전 세트 7개: 배민 Limited 5개 130,000원, CU QR 5종 44,500원, CU Wappen 2개 22,200원, 메이크스타 털실냥이 Standard 5개 104,000원, 메이크스타 한입만 쇼케이스 Standard 5개 104,000원, 후즈팬 Wappen 5개 55,500원, 후즈팬 쇼케이스 Standard 5개 104,000원. 모두 상품 합계 564,200원·실물 32개입니다. CU Wappen 가격은 사용자가 22,200원으로 정정했습니다.

배민·CU·메이크스타 단품 특전도 후보입니다. 메이크스타 단품 가격·조건은 공식 페이지, 배민/CU 단품의 랜덤 1장 조건은 사용자 안내 기준입니다. 앱 가격을 직접 조회하지 못한 배민/CU 단품은 기준가로 표시하고 별도 가격 편집을 지원합니다. CU는 10-14 15:00 오픈 예정 안내이며 실제 상태를 포켓CU에서 확인해야 합니다.

특전 수량은 사용자 안내의 앨범당 랜덤 1장과 세트 중복 없음 조건을 반영합니다. CU QR 세트는 개인 미공포 5장, CU Wappen 세트는 유닛 미공포 2장으로 비교합니다. 앱의 현재 실제 조건과 대조한 확정값이라는 뜻은 아닙니다. 특전 종류별 최소 중복 없는 수량을 별도 평가하되 봉입 포카 장수·완성 확률에는 더하지 않습니다. 판매처·이벤트별로 합산한 수량이며 전체 사진 도안을 대조한 전종 수가 아닙니다.

설문은 특전의 개인/유닛 종류와 수집 비중을 선택합니다. `pobPriority: one`은 추가 특전 수량 점수 0, balanced는 포카 우선일 때 장당 18점/그 외 8점, collect는 장당 40점입니다. 가중치는 취향 가이드이며 공식 점수나 금전적 가치가 아닙니다. 모든 판매처에 동일한 기준을 적용합니다. 랜덤 반복 구매는 종류별 최소 1종, 같은 중복 없는 세트의 반복 구매는 해당 특전의 수집 가치를 중복 가산하지 않습니다. 확인된 메이크스타 한 주문 5매 증정 문턱은 동일 이벤트 안에서만 합산합니다.

특전·응모 상품에 든 앨범을 수집 목표에 먼저 반영하고 부족한 물량만 추가합니다. 추가 앨범에 동일 제품 단위의 특전 상품이 공구가보다 같거나 낮으면 실제 특전 상품으로 연결할 수 있으며 그 물량은 해당 상품 가격으로 계산합니다. 예산·보관 상한은 늘리지 않습니다. 후보 비교표에서 CU QR 등 후보의 검토 수량·금액과 예산/보관/CD/배송 등 제외 사유를 표시합니다.

## 쇼케이스

[메이크스타 공식 이벤트](https://www.makestar.com/product/21196): 2026-10-13 15:00~10-16 23:59 KST 응모, 370명 선발, 10-20 18:00 이후 발표, 11-03 20:00 블루스퀘어 우리WON뱅킹홀 행사. 본 이벤트 Standard 단품 20,800원은 응모 1회, 5매 104,000원은 5회입니다. 동일 응모자의 주문은 구매 수량 기준 합산됩니다. 응모하지 않아요 선택 시에도 특전은 제공됩니다. 타 판매처와 중복 당첨은 불가합니다.

일반·공구·털실냥이·배민·CU 앨범은 쇼케이스 응모 횟수에 넣지 않습니다. 후즈팬 행사 상품은 안내하지만 환산·마감·선발 조건을 모두 확인하지 못해 메이크스타 횟수와 합산하지 않습니다. target은 개인 목표이고 priority는 예산/보관 상한 내 응모 수량 최우선입니다. 확인된 응모 우선순위는 특전 점수보다 먼저 비교합니다. 당첨 컷·개인 당첨 확률은 계산하지 않습니다. 시작 전/마감 후 추가 응모용 앨범 구매를 중단합니다. 값은 구매 계획이며 실제 응모 완료 증명이 아닙니다.

## 계산과 검증

10개 질문으로 성향을 분류하며 등급은 팬심이나 구매 권장 강도가 아닙니다. 금액 무제한도 보관 상한 1~100개를 유지합니다. 추천은 실물·봉입·특전 효용을 비교하고 동점이면 배송비 포함 금액이 낮은 조합을 선택합니다.

봉입 확률은 한 팩 내 균등 비복원 추출, 팩 간 독립 추출을 가정한 동적계획 계산입니다. 종류별 확률이지 모든 종류 동시 완성 확률이 아닙니다. QR 버전별 확률은 실제 5종 세트 개수를 사용하고 랜덤 단품을 제외합니다. 교환 전제 QR 전종 최소는 2세트이며 교환 성사·완성을 보장하지 않습니다. 봉입 전종 교환 최소 수량은 Standard 5 + Limited 5 + QR 10 + Wappen 5 = 실물 25개이고 ALL MD 상품 합계 307,900원입니다. 특전 상품을 포함한 실제 추천 가격은 별도입니다.

```sh
node pulse-fit/test-engine.cjs
node pulse-fit/test-ui-render.cjs
```

65개 계산 검증 및 10개 질문/주요 화면 템플릿 검증을 실행합니다. 일반가 대비 공구가, 이전 링크의 공구 제외 설정 전환, 공구 배송비와 무료 기준, 이벤트 가격과 응모 수량 유지, 특전 수량 가치·반복 구매 과대 계상 방지, 공구 마감 후 참고값, 금액·수량·카드 합계 정합성을 확인합니다. UI는 최소 document facade 기반 템플릿 검증이며 브라우저 레이아웃 검증은 아닙니다.

GitHub Pages 워크플로에서 계산/UI 검증 후 배포하고 로그인 없는 공개 URL의 HTML/CSS/JS가 해당 커밋 파일과 바이트 단위로 일치하는지 확인합니다. 가격을 자동 수집하지 않으며 구매 전 전용 링크·실제 상품 조건을 확인해야 합니다.
