# RESCENE RECORD · 리센느 기록실

리센느 전곡을 차트별로 함께 비교하는 비공식 팬페이지입니다. 기존 투표 트래커와 별도 저장소에 배포합니다.

- 멜론: TOP100, HOT100 30일·100일, 일간, 주간, 월간, 확정 연간 차트
- 지니: 실시간·일간 / FLO: FLO 차트 / 벅스: 실시간·일간 / 바이브: 일간
- 써클: 주간 디지털 / 유튜브: 주간 인기곡·주간 뮤직비디오
- 음원사이트 선택 시 함께 보기·독립 캔들·기록 표의 차트 종류를 해당 사이트 제공 목록으로 전환
- 기본 기간: 2024-03-26 데뷔일부터 마지막 집계까지 (KST)
- 차트별 실제 진입곡만 범례·표에 표시, 곡별 고유 색상과 선택 체크, 전체 표시·숨기기
- 데뷔일부터 기록 유지, 최근 구간 기본 표시, 휠 좌우 이동·Ctrl+휠 확대/축소, 이동·확대 버튼, 전체 기간 보기
- 일간·주간·월간·연간의 굵은 100위 진입선
- 함께 보기와 독립된 MTS 스타일 캔들 영역. TOP100·HOT100 시간봉, 일간 일봉, 주간 주봉, 월간 월봉, 연간 연봉
- 캔들 시가 = 직전 집계 순위, 종가 = 해당 시점 순위. 몸통은 두 순위를 연결하며 순위 상승은 빨강, 하락은 파랑. 직전 집계가 없거나 기록이 끊긴 경우 단일 순위 표시
- 캔들 휠 이동·Ctrl+휠 줌, 모바일 드래그·두 손가락 핀치. 캔들 영역에만 touch-action:none을 적용해 페이지 제스처와 구분
- 얇은 추이선, 마우스·터치 위치의 집계 시각 및 곡별 순위 툴팁
- 기록 표의 독립 차트 선택, 선택 기간 최고 순위 오름차순 정렬
- 기간 선택, 일간 1–1,000위 눈금
- 같은 제목의 다른 녹음·언어·인스트루멘털은 가이섬 동일곡 연결 정보로 구분. 유튜브 뮤직비디오는 영상별 ID를 별도로 보존
- 순위는 공개 자료의 실제 관측값만 저장. 누락 구간을 보간하거나 연간 순위를 계산하지 않음

## 데이터

출처: [가이섬](https://xn--o39an51b2re.com/). 모든 플랫폼의 순위·과거 기록·동일곡 연결은 가이섬의 공개 페이지 JSON을 읽습니다. 멜론 곡 목록은 기존 Melon 아티스트 페이지를 보조적으로 유지하며, 다른 사이트 곡 ID를 제목만으로 추정하지 않습니다. 유튜브 영상 목록은 가이섬의 리센느 아티스트 페이지와 공개 검색 목록에서 확인합니다. 차트·캔들·기록 표에 해당 가이섬 원본 링크를 제공합니다.

현재 최신 표 제공 범위는 멜론 일간 1,000위, 지니 250위, FLO·벅스·유튜브 100위, 바이브 300위, 써클 200위입니다. 과거 곡별 기록에 이 범위 밖 순위가 제공되면 실제 값을 보존합니다. 주간·월간·연간 점은 집계 기간 끝 날짜에 놓고 원본 기간 시작 날짜를 함께 저장합니다. 누락 시점은 연결하거나 보간하지 않고, 완전한 최신 표에 없는 곡은 집계 범위 밖으로 표시합니다. 과거 최고 순위는 확인된 관측값 기준입니다. 존재하지 않는 사이트별 차트 종류는 생성하지 않습니다.

자동 수집은 플랫폼·차트·곡 ID·아티스트와 응답의 완전성을 확인합니다. 실패한 요청은 마지막 성공 기록을 유지하고 오류를 기록합니다. 시가로 쓰는 직전 집계는 실제 연속 시간·일·주·월·년에만 연결합니다. 유튜브의 인기곡과 뮤직비디오 기록을 합치지 않습니다.

## GitHub Pages 배포

1. 새 공개 저장소 `rescene-record`를 만들고 이 폴더의 파일을 올립니다. 기존 투표 저장소에 올리지 않습니다.
2. Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
3. Actions의 **Collect charts and publish Pages**를 실행합니다.
4. 주소: `https://사용자명.github.io/rescene-record/`

매시 01분에 최신 차트 표를 수집하고 데이터를 저장한 뒤 배포합니다. 새로 확인된 곡은 과거 기록도 자동으로 확인합니다. 매주 일요일 00:01 KST에는 전곡 과거 기록을 다시 확인합니다. GitHub 스케줄 실행에는 지연이 있을 수 있습니다. 실패한 개별 출처는 마지막 성공 기록을 유지합니다. 과거 전체 기록 재확인은 Actions 수동 실행에서 `backfill`을 체크합니다. 초기 과거 기록은 함께 제공되는 `data/`에 들어 있습니다. 공개 사이트에 부담을 줄이도록 요청을 제한합니다.

## 로컬 실행

```sh
python -m pip install -r requirements.txt
python scripts/collect.py          # 최신 기록 추가
python scripts/collect.py --backfill # 공개 곡별 과거 기록 재확인
python -m unittest discover -s tests
python scripts/build.py
npm ci && npm test
python -m http.server 8000
```

`index.html`은 데이터를 포함하므로 파일을 직접 열어도 작동합니다. 데이터 오류·출처 변경 시 수집기는 잘못된 응답을 덮어쓰지 않고 오류를 기록합니다.

글꼴은 Google Fonts의 Noto Sans KR 일부 문자 글꼴을 포함합니다. 라이선스는 `FONT-LICENSE.txt`를 확인하세요.

모바일 가독성: 선 차트 기본 화면은 일간 30일·시간별 2일, 캔들은 40봉입니다. 차트 내부에서 한 손가락 이동·두 손가락 핀치 확대/축소를 지원하며 페이지 전체 확대는 차트 밖에서 유지됩니다. 탭한 순위는 왼쪽 점선과 등수 배지, 곡명은 오른쪽에 표시하며 상세 기록은 차트 아래에 표시합니다.

상위권 간격 확대를 기본으로 적용합니다. 세로축은 순위의 로그 눈금으로 상위권을 넓게, 하위권을 좁게 표시하며 실제 순위 값은 변경하지 않습니다. 체크를 해제하면 기존 균등 눈금으로 돌아갑니다.

곡 선택 목록은 해당 차트의 최신 집계 순위가 높은 순으로 정렬하며 배지에도 실제 최신 등수를 표시합니다. 최신 집계에서 차트 밖인 곡이나 기록 없는 곡은 뒤에 배치합니다. 그래프 오른쪽에는 화면 구간 끝에서 확인된 실제 등수와 곡명을 표시합니다. 곡별 색상은 정렬과 무관하게 유지합니다.

최신 스냅샷 수집 실패 또는 해당 시간의 실시간 차트가 아직 공개되지 않은 경우, 실패·미갱신 차트만 20초 간격으로 재확인합니다. 재시도 창은 최초 수집 후 최대 10분입니다. 일간·주간·월간·연간이 이전 집계 기간을 유지하는 것은 정상이며 이를 미수집으로 판단하지 않습니다. 재시도 종료 후에도 미수집이면 마지막 성공 기록을 보존하고 다음 예약 실행에서 다시 확인합니다. 매주 일요일 00:01은 예약식을 분리해 매시간 수집과 중복 실행되지 않고 한 번의 전체 재확인으로 처리합니다.

모바일 곡 선택 목록은 가로 스크롤 없이 화면 너비 안에서 여러 줄로 줄바꿈합니다. 긴 곡명도 버튼 내부에서 줄바꿈해 화면 밖으로 넘치지 않도록 합니다.
